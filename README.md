# FX Channel

A synchronized, mobile-first FX channel built from the same full-channel pattern as the rest of the Infinity TV network.

## Programming rule

The lineup favors FX's historically important, highly watched, or critically acclaimed originals and the newest FX slate, plus selected PG-13 movie-night titles that are actually appearing in FX programming. Playback uses official public video sources; the site does not substitute pirated full episodes when an official embeddable episode is unavailable.

The daily order refreshes at the viewer's local midnight and includes a seven-day guide, live sync, rewind/start-over, channel remote, share reward tracking, Infinity Phi search, and official full-series links.
